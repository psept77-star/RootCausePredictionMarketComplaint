# Automated Market Complaint Root Cause Predictor

An end-to-end machine learning solution developed in Python to streamline and automate quality assurance workflows for manufacturing and pharmaceutical market complaints. By processing raw, unstructured text descriptions, the system instantly identifies the underlying Root Cause of a complaint, significantly minimizing manual engineering review times and accelerating corrective action implementations.

✨ Key Features
• Automated Model Selection: Evaluates and optimizes multiple core machine learning frameworks—including Logistic Regression, Random Forest, Naive Bayes, and XGBoost—leveraging automated GridSearchCV hyperparameter tuning and StratifiedKFold cross-validation.
• Interactive Evaluation Dashboard: Integrates an on-demand ipywidgets dashboard allowing quality teams to input a product name and complaint description to instantly see the predicted root cause report.
