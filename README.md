# RootCausePredictionMarketComplaint
Predict Root cause of new Market complaints based on Product name, Complaint narrative o	Benchmarked 4 machine learning pipelines (Logistic Regression, Random Forest, Naive Bayes, XGBoost), with Logistic Regression and Naive Bayes achieving peak accuracy on the stratified evaluation dataset. 
o	Built an interactive, functional deployment simulation using ipywidgets to dynamically predict classification categories like Manufacturing, Packaging, Distribution, or Patient Misuse.
